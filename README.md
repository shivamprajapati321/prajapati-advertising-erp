# Prajapati Advertising — Operations Suite

Internal admin platform for **Prajapati Advertising**:

- 📦 **Dispatch Management** — multi-line item entry
- 🏭 **Vendor Master** — multi-contact CRUD  
- 📑 **Work Orders** — client orders
- 💰 **Payments** — full ledger with mode tracking
- 📈 **Reports** — 4-dimension analytics

## Stack
- HTML + Vanilla JS + Supabase + Vercel
- Plus Jakarta Sans + JetBrains Mono fonts

## Pages
| File | Purpose |
|---|---|
| `index.html` | Dashboard |
| `dispatch-new.html` | New Dispatch form |
| `dispatch-list.html` | All dispatches |
| `dispatch-pdf.html` | Printable slip + WhatsApp share |
| `vendors.html` | Vendor master |
| `work-orders.html` | Work orders |
| `payments.html` | Payment ledger |
| `reports.html` | Analytics |
